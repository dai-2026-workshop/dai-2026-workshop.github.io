# DAI 2026 Workshop site

Standalone static GitHub Pages site for the DAI 2026 AI Scientist & Agents Workshop. The English page is at `/`; the Simplified Chinese page is at `/zh/`. Each page uses one language, with a navigation link to switch between them. The site uses static HTML, CSS, speaker photos, and poster-derived logo and QR assets in `assets/`; there is no build step or external asset dependency.

## Published site

The site is published from the public repository `dai-2026-workshop/dai-2026-workshop.github.io` at `https://dai-2026-workshop.github.io/`; Chinese is available at `https://dai-2026-workshop.github.io/zh/`. GitHub Pages deploys from the `main` branch and `/ (root)`.

The organization and repository are public so the site can be hosted on the GitHub Free plan.

## Source scope

The site follows the supplied workshop poster and speaker materials. It lists the workshop on Sunday, 29 November 2026 at City University of Hong Kong, with all times in Hong Kong Time (HKT, UTC+8). The livestream reminder QR and DEEPEX logo are taken from the supplied poster. Lianghao Xia's expanded biography, talk title, and abstract come from the later program update supplied for the site. Speaker biographies and talk abstracts are shown in expandable sections.
